# IK / 路径约束入口与控制点拾取

## 操作入口

选中骨骼，在右侧属性上方展开的「控制与约束」区操作：

- 显示当前骨骼是控制点、受约束骨骼，还是尚未绑定 IK/路径约束。
- 「配置 IK · 1–2 根骨骼」或「配置路径 · 整条骨链」打开现有约束；列出约束驱动的骨骼。
- 「选择控制点」直接选择目标骨骼并切换移动工具。路径控制点从路径顶点权重读取，未按 tail_* 名称硬编码。
- 设置模式提供「新建 IK 约束…」「新建路径约束…」。动画模式保留导航，禁用结构创建并提示切回设置模式。
- 移除骨骼标题旁重复的旧小 IK 按钮。路径约束属性也可直接跳到控制点。

现有绑定的 IK 与路径不是同一个可随意切换的开关；入口明确区分两类约束。原有创建/配置数据流程保持不变。

## 画布

IK 控制点用黄色标记，路径控制点用青色标记，显示独立圆形手柄与类型名称。普通骨骼的重复文字被抑制，控制点标签在画布边缘避让。控制点显示半径 10 像素，拾取半径 12 像素，不随画布缩放缩小。

在标记范围内，控制点优先于更近的普通骨干；从其他对象切换时也优先于原选中对象的移动/旋转手柄。保持抓取偏移，不会把控制点突然吸到鼠标位置。关闭骨骼显示、皮肤未激活的控制点不参与控制点优先拾取。专用网格/路径顶点编辑仍使用自身输入流程。
