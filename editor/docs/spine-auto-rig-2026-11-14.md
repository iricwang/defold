# 05_tail 自动布网、布骨与绑定

## 操作

设置模式下选择图片或独立网格附件，点击属性中的「自动布网与骨骼…」。第一版是尾巴／触手类连续细长部位，不做整个人物的解剖识别。

- 骨骼数量 2–32，控制点数量 2–8；预览中调节数量，或交换根部与末端。
- 拖动金色编号控制点调整生成位置；控制点应留在网格覆盖区域内，超出则显示错误并禁止确认。
- 轮廓描绘后沿中轴补内部顶点，显示轮廓、骨骼和可切换三角线。
- 确认一次性创建独立命名的骨骼、加权路径与自动网格权重。新路径使用 Chain + Length + spacing 0，默认不伸缩。
- 生成后使用标准控制点移动与关键帧流程。整次生成支持撤销／重做；预览内控制点拖动支持撤销／重做。取消或关闭预览不修改文档。
- 调整数量发生在生成预览内。再次对同一附件生成会创建新的命名组，保留原骨骼；不自动删掉已有骨骼或迁移原骨骼关键帧到新骨骼。

## 实现范围

编辑器侧用原有 Python 环境的 OpenCV、NumPy、SciPy 提取透明轮廓中轴，不下载模型或新增 Python 依赖。中轴分析限制到 256 像素长边，使用两阶段细化和稀疏图主路径，再用原图内部像素校正细尖端。存在明显多个独立部位时拒绝自动连骨。

按弧长采样骨骼；根尾方向可手动交换。内部网格顶点与现有轮廓一起通过已有拓扑转移逻辑处理。复用编辑器沿网格表面距离计算的自动权重，最多 4 个骨骼影响；不是 Spine 私有自动权重算法。

沿用原附件与现有骨骼，旧 FFD 数据通过现有重映射逻辑处理。更换绑定会改变动作控制关系，不能把数据保留解释为旧动画视觉完全不变。新生成骨骼采用标准 Spine 骨骼／路径／权重字段，没有更改运行时引擎。

预览异步计算并丢弃过期结果；图像中轴、轮廓和各骨骼数量的网格分别缓存。控制点位置变化复用已细分网格。实测本例初次完整生成约 5–6 秒，数量变化约 3–4 秒（含已有动画的拓扑转移和完整导出校验）；后台运行期间编辑线程不执行这些计算。

- cljfmt 与 git diff --check 通过；clj-kondo 0 errors，28 个既有 warnings，本次新增代码无警告。
