# 属性结构与网格恢复图片

属性沿用骨骼编辑器灰色主题。基础信息使用标签/输入行，变换按位置、旋转、缩放、尺寸分行，双轴并排；网格工具使用两列按钮。约束等数值字段改为同行布局，复杂数据继续放在可折叠分组内。窄侧栏中的骨骼下拉框可缩小，弹出列表仍按完整名称测量。权重、皮肤分页保持可用。

网格工具增加“恢复为图片”，替代已创建网格状态的创建按钮。附件管理页同样提供入口，覆盖普通网格、描绘网格、带骨骼权重网格及关联网格。通过 UV/设置姿势顶点拟合图片矩形，保留路径、尺寸、颜色和插槽；矩形图片不保留非刚性网格扭曲。该附件的网格权重与变形轨道被移除，骨骼及约束保持不变。有关联子网格时先转为独立网格并复制其继承的变形轨道，避免父网格恢复后链接失效。撤销恢复完整文档。

验证：162 项回归 / 1510 条断言通过，覆盖图片位置和镜像、Spine JSON 导出再导入、权重网格、关联子网格及继承变形、控件调用和撤销/重做。tail 示例副本 34 步后台交互通过：恢复原网格、创建 3×3 网格、恢复图片、连续撤销、权重分页、骨骼属性。截图验证 260px 窄侧栏字段和控件没有溢出。后台 native Metal / Scene3D，禁用处理器与停止计时器均为零。示例的自动 Play 准备提示不作为此次运行时验证结果。
