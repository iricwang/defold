# 权重页骨骼选择联动

- 骨骼列表随属性页可用高度伸展，较矮窗口仍可滚动。
- 权重页点选画布或层级树骨骼时保留当前网格。已绑定骨骼在列表高亮，显示移除；未绑定骨骼显示绑定。
- 添加骨骼保留已有权重，新影响初始权重为零；可通过自动权重或手动赋值继续分配。移除与添加都支持撤销。
- 绑定后以及撤销后重新计算高亮，不沿用过期选择。
- 修复骨骼列表与影响数量滑块的控件 ID 冲突。
