## 已落地

属性侧栏使用“属性 / 权重 / 皮肤”三个入口。G 或权重页签进入权重工具。
保留上一轮 N 创建、Shift 同级创建、Option 重建和 Cmd 附件辅助创建。

选择网格后点击绑定，在画布或层级树点选骨骼；也支持先选骨骼后选网格。
空格完成绑定且不启动播放，Esc 取消，选择阶段不写入文档。
首次绑定自动分配，修改已有绑定列表保留已有骨骼权重／绑定坐标，新增骨骼从零开始。
权重列表只列已绑定骨骼；有差异的多顶点值显示 *。
直接滑块及数值框、平滑、修剪与显式自动计算集中显示。
滑块初值来自选中顶点平均权重，拖拽只在释放时提交一次。
移除骨骼重新分配剩余权重；移除最后一根则还原插槽坐标下的无权重网格。

皮肤面板不依赖附件选择。活动皮肤切换、新建、复制、删除和高级组合集中管理，
从每个附件的属性中移除重复组合控件；default 禁止删除。动画模式禁用皮肤结构编辑。
新空皮肤保留 default 共享附件回退，不删除图片文件。

## 明确边界

当前自动权重继续使用已有骨段距离算法，不等同于 Spine 的拓扑感知算法。
此轮没有实现 Spine 全套权重饼图、固定多皮肤预览或完整皮肤占位符拖放。
已有备用附件迁移保护继续有效，不宣称全部多蒙皮重建兼容。
后续高优先级：拓扑感知自动权重、权重颜色图例／叠加、皮肤占位符与固定预览。
