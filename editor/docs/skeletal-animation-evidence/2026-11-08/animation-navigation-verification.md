# 全节点时间轴与动画快捷键（2026-11-08）

单选骨骼／插槽／约束时聚焦对应轨道；空选、多选时显示当前动画中所有有关键帧的节点轨道。摄影表包含骨骼、插槽、网格变形、约束、事件、绘制顺序和序列轨道；曲线页显示其中支持曲线编辑的数值通道。节点名与属性联合标识通道，避免多个节点的“旋转”重名导致误编辑。轨道结果使用单项缓存，在文档或选择改变时失效。

| 按键 | 操作 |
| --- | --- |
| Space | 播放／暂停；松键时切换一次，长按不反复切换 |
| ← / → | 前／后一帧；长按可连续逐帧 |
| Shift + ← / → | 前／后 10 帧 |
| Alt + ← / → | 上／下一个关键帧，按当前显示轨道范围查找 |
| Home / End | 动画起点／终点 |

定位和逐帧会暂停，时间与预览时间同步并限制在动画时长内；从结尾再次播放从起点开始。文本框、数值框、下拉框保留原键盘行为，树的箭头与 Home/End 保留层级导航。清空画布选择继续使用 Esc 或点击空白，Space 不再清空选择。工具栏和键盘共用 transport 状态逻辑。

129 项测试、926 条断言通过。新导航模块、工具栏及导航测试 lint 无错误和警告，已有 view/curve 文件保留原警告。用 cljfx.plorer 在本地 Defold 验证空选全轨道、Space 播放／暂停、逐帧、十帧、关键帧、首尾定位、输入框防误触。实机样例出现 8 条轨道，包括 05_tail 的 deform。验证前后资源文档一致，保留原有未保存状态，没有保存游戏文件。
