# 骨骼编辑器属性面板整理

2026-11-08。已实现到源代码，并在本地 patch.127 编辑器热加载验证；尚未制作新增量包。

## 显示原则

属性按当前对象和工作模式组织。常用值直接编辑；低频结构操作折叠；只在适用类型出现的字段不占位。隐藏或折叠只影响界面，不删除原文件数据。折叠偏好属于编辑器会话，按对象种类和模式保存，属性重建、换对象和移动播放头时复用，不写入游戏资源。

| 内容 | 用户是否需要编辑 | 当前安排 |
| --- | --- | --- |
| 对象名称、所属骨骼、图片资源 | 是，设置阶段常用 | 设置模式保留；动画中的附件名称仅作只读标识 |
| 骨骼位置、旋转、缩放 | 是，高频 | 合并为“变换”，X/Y 成对排列 |
| 倾斜 | 是，低频 | 变换组中的独立折叠项 |
| 骨骼父级、继承、长度 | 是，绑定阶段使用 | 合并到“骨骼结构”；动画模式不显示 |
| 顶点选择、顶点权重 | 是，网格编辑时使用 | “网格与权重”默认折叠，仅设置模式显示 |
| 拓扑、重建、描摹、权重笔刷、镜像 | 是，专业操作 | 网格组内按用途细分，保持原有数据保护及撤销 |
| 混合模式 | 是，外观设置 | 默认展开，选项显示正常、叠加、正片叠底、滤色 |
| 附件名称、类型、默认附件、创建/删除 | 是，资源管理 | 放入折叠的“附件管理”；完整编辑表单不与主面板同时展开 |
| 原始顶点数组 | 常规制作不需要直接输入 | “高级附件数据”默认折叠；保留给专业修复与附件创建 |
| 链接网格父附件、蒙皮、继承变形 | 仅链接网格需要 | 仅链接网格类型显示 |
| 裁剪结束插槽 | 仅裁剪附件需要 | 仅裁剪类型显示 |
| 序列帧资源配置 | 仅序列贴图需要 | 设置模式可展开配置；动画模式仅已有序列时出现播放与打帧控件 |
| 附件切换、颜色、透明度关键帧 | 是，动画阶段常用 | 动画模式单独分组，默认展开 |
| 双色暗部颜色 | 仅双色轨道需要 | 仅双色选项显示；普通颜色与透明度轨道隐藏 |
| 绘制顺序关键帧 | 是，低频 | 动画模式单独折叠，保留排序与打帧操作 |
| 皮肤归属、组合皮肤 | 是，多皮肤制作时使用 | 设置模式折叠；动画模式不混入结构编辑 |
| 约束目标、受约束骨骼、执行顺序、模式 | 是，绑定阶段使用 | 合并为“约束关系”折叠组，主要动画值保留在外 |
| 变换约束偏移、物理求解设置 | 是，低频 | 单独折叠，保持原参数语义 |
| 事件参数与音频 | 是，仅选中事件时使用 | 保留事件专属面板，不并入普通骨骼/附件属性 |
| 运行时矩阵、缓存、采样状态、内部标识 | 无需作为常规属性编辑 | 不新增到属性界面，诊断需求应进入调试信息 |

附件库表单保留创建/编辑完整附件的能力，因此其中的路径和变换仍存在；它们默认折叠，普通的当前附件编辑不必打开该表单。底部变换工具仍作为画布快捷操作入口保留。

## 验证

独立 JVM 57 项回归、380 条断言通过，包括原有插槽打帧、撤销事务边界、过期属性控件保护和空选中保护。新增检查覆盖模式隔离、字段随类型切换、双色颜色字段、折叠状态重建保留与文档不变。公共分组组件、附件面板及相关测试 clj-kondo 无错误无告警；主视图保留既有 lint 告警。

通过 cljfx.plorer 在 rat.skeleton 验证骨骼/网格布局、展开后切换对象保留状态、动画模式隐藏结构操作、单色隐藏暗部颜色与空白取消选择。原游戏文档未修改。截图位于 `skeletal-animation-evidence/2026-11-08/properties-organized-*.png`。
