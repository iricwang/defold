# IK 与路径约束的骨骼长度控制

## 原因与 Spine 对应关系

现有 `05_tail` 路径案例使用 `rotateMode=chainScale` 和比例间距。这会沿骨骼 X 轴缩放以贴合路径，是示例选择了可伸缩配置，并非 IK 求解器无条件改变骨长。

- [Spine IK 约束](https://esotericsoftware.com/spine-ik-constraints)：Stretch 允许目标超过可达距离时伸长；Compress 适用于单骨骼 IK。属性可记录动画关键帧。
- [Spine 4.2 运行时 API](https://esotericsoftware.com/spine-api-reference-4.2)：路径的 Chain 不主动缩放骨骼；Chain Scale 会缩放到下一个采样位置。Length 间距按骨长排列；Proportional 根据路径总长分配。
- 已对照项目固定版本 `@esotericsoftware/spine-core` 4.2.120 的 `IkConstraint.js` 和 `PathConstraint.js`，沿用标准字段，未更改求解器或运行时引擎。

## 编辑器操作

选中受约束骨骼或其控制骨骼，在右侧「控制与约束」区设置：

- IK：增加直接可见的「允许拉伸」「允许压缩（单骨骼）」控件。约束属性的「骨骼长度」分组使用相同逻辑；两骨骼 IK 禁用不适用的压缩选项。动画模式沿用自动关键帧／待提交姿势的原有规则。
- 路径：「保持骨骼长度」一次性设置 Chain、Length、间距 0；「伸缩以贴合路径」设置 Chain Scale、Proportional、间距 1。配置作用于该约束的全部受控骨骼；不是独立的逐骨骼运行时锁定。
- 自定义配置显示「自定义（高级设置）」，不在加载时偷偷改写。路径结构模式只在设置模式修改；已有动画关键帧不删除。已有间距动画仍按新间距模式解释，必要时需按项目设计调整。
- 超出可达范围时，固定长度模式不保证尾尖触及路径末端。它约束的是约束求解产生的缩放，并不禁止美术手动缩放骨骼或继承父级缩放。
- 切换可撤销／重做，不修改网格权重或原始骨骼长度。

新生成的独立尾巴示例默认使用固定长度模式，生成器仍补偿绑定坐标以保持静态网格姿态。已有项目和用户正在编辑的尾巴文件未覆盖，需主动选择所需长度模式。
