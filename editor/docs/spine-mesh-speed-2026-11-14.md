# 布网整数参数、预览计算与加载反馈

2026-11-14。仅修改 Editor；运行时引擎、安装包保持不变。已热更当前本机 Defold，会话结束后需重新热更或安装后续增量包。

## 参数与反馈

智能布网、自动布网与骨骼共用整数输入：滑杆步长为 1，文本提交或失焦后四舍五入并限制范围，非法输入恢复当前值。统一参数改为 `uniform-percent`（0–100），旧 `uniform` 比例配置自动迁移；算法内部仍使用对应比例，结果不变。空间坐标/控制点仍保留浮点精度。

底部面板正上方显示转动指示器和“正在计算…”。调参等待、计算中保持显示，完成/失败/取消后隐藏。加载位置保留空间，避免画布缩放跳动。计算期间禁用确认；重复输入同一整数不重新提交；版本检查与参数匹配阻止过期预览落地。

## 性能

- 生成骨骼批量加入并校验，避免每根骨骼重新验证全部网格和动画；同时避开原始数据中保留的骨骼名称。
- 轮廓与骨骼中轴分析并行执行。
- 内部 Spine 导出采用数据映射，避免格式化 JSON 再解析；完整导出/导入校验保留。
- 复用已验证的导出数据进行网格细分；预览缓存按参数、图片修改时间和大小失效，数量有界，相同参数刷新直接复用。

同机、同一 05_tail、独立编译 JVM、detail=12，依次执行：

| 操作 | 原版首次 / 预热后 | 优化首次 / 预热后 |
| --- | --- | --- |
| 打开新预览，8 骨骼、3 控制点 | 6887 / 5056 ms | 4364 / 3375 ms |
| 调整为 12 骨骼、4 控制点 | 3761 / 3369 ms | 1976 / 1902 ms |
| 调整为 5 控制点 | 2331 / 2259 ms | 1179 / 1385 ms |

缓存命中时间不代表冷计算时间。仍有子进程启动和整份文档校验成本。两版生成文档在解析保留 JSON 后语义完全一致；顶点数量分别保持 68、76。
