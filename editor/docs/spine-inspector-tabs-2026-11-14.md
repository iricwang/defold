# 属性窗口与权重分页

根据用户提供的属性面板参考图调整编辑器，运行时引擎和资产格式不变。

- 统一属性 / 权重 / 皮肤分页。移除旧独立权重栏，保留绑定、自动权重、平滑、裁剪、焊接、复制/粘贴、骨骼影响列表等功能。
- 深灰面板、蓝色分页下划线、细边框控件；窄栏标签可换行。权重列表高度由 450 调整为 190，内部滚动。
- 动画属性集中显示自动关键帧、当前帧、对象名称、编辑网格、附件、颜色/透明度、插值、绘制顺序。
- 空心/蓝色实心菱形区分未记录与已记录关键帧，依据已提交基线而非尚未记录的姿势。菱形右键提供删除关键帧，沿用原有撤销事务。

- 顶部锁定按钮锁定属性页编辑（不是锁定当前选择）；更多菜单展开/折叠分组。
- 设置模式继续提供原有建模能力，动画模式不暴露设置姿势写入。
