# 自动尾巴路径绑定：层级与控制点界面整理

`control1 / control2` 是可拖动、可设关键帧的控制骨骼；本例分别对应尾根和尾尖。它们通过权重改变 `05_tail_auto1_path` 中的路径附件。`05_tail_auto1_follow` 是路径约束，让 8 根驱动骨骼沿该路径排列；骨骼再通过网格权重带动尾巴。`path` 是存放路径附件的插槽，不是另一根骨骼；`follow` 也不是骨骼。

改动仅涉及编辑器表现，不更改实际父子关系、名称 ID、约束、权重、动画或运行时引擎。

- 有效的自动路径绑定显示为 `05_tail · 路径控制`，放在原父骨骼下；控制点 1、2 放在前面，驱动骨骼与高级路径数据默认折叠。
- `follow` 保留为可选择的组标题，点击进入路径跟随设置；`path` 显示为“路径形状”，高级原始顶点数据默认折叠。
- 属性面板的控制点选择器是固定大小的数字按钮，随侧栏宽度自动换行，互斥高亮；完整 ID 保留在提示及辅助功能文本中。超过 9 个控制点仍按自动绑定顺序排列。
- 已绑定骨骼隐藏无关的创建约束按钮，名称编辑与底层路径跟随参数折叠；移动、旋转、缩放保留。普通 IK 的长度快捷操作保留。
- 失效自动绑定元数据、自定义父子关系、同一骨链多重约束不会强行分组。原始 ID 可搜索、可选，显示别名也参与搜索。
