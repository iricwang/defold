# Spine Smart Mesh 编辑器接入

接入现有骨骼编辑器，不修改运行时引擎。当前通过本地 Python 子进程调用用户安装的 `spine-smart-mesh`，不启动独立网页工作台。

## 操作

1. 打开或新建 `.skeleton`，在“项目 → 导入 Spine”选择 `.spine`。已支持的 4.2 工程仍由现有独立编解码器处理；不支持的原生格式转交本机 Spine CLI。
2. 在骨架层级中选中普通图片附件，展开“属性”，点击“智能布网”。根据 PNG 透明轮廓生成三角网格，默认绑定当前插槽骨骼。结果作为一次编辑事务提交，可撤销/重做。
3. 在网格工具中继续编辑，或播放原动画检查效果。保存 `.skeleton` 保留编辑数据；“保存 Spine 工程”另存新的原生工程，连同独立图片/事件音频目录一起输出。
4. 原生保存会回读并比较骨骼、插槽、动画、约束、附件、三角面、约束边与权重；仅接受默认值省略、浮点舍入、恒值线性段转阶梯等已识别的规范化。已有目标工程及资源目录不会覆盖。

## 本机依赖

- 工具目录内存在 `mesh.py`、`app.py`、`.venv/bin/python` 及工具所需依赖。
- 可设置 `DEFOLD_SPINE_SMART_MESH` 指定工具目录；否则向游戏工程上级查找 `tools/spine-smart-mesh`，导入时也会向源工程上级查找。导入后的 `.skeleton` 记录已使用的工具路径。
- 原生兼容导入/保存需要已安装并激活的 Spine Professional；当前工具支持 4.2.43 / 4.3.26。自动布网本身只调用 Python 算法。
- 桌面宿主的 `CFProcessPath`、JavaFX 应用身份和 JVM 注入环境不会传给 Spine，避免 CLI 被错误启动为 GUI。任务在后台执行，超时终止子进程；中间导出放临时目录并清理。

## 范围

- 当前自动处理选中的普通 region 图片附件；已有 mesh、linked mesh、序列附件和 deform 不自动重建。
- 自动生成采用 rigid 绑定，不推测关节的父子骨骼和弯曲方向。工具检测到其不支持的约束/继承组合会明确拒绝，原文档保持不变。
- 4.3 原生 CLI 通道目前仅处理单骨架。多骨架 4.2 保持既有独立导入流程。4.3 数据不能误交给 4.2 编码器保存。
- 这是编辑器验证范围，不等同于证明所有 Spine 4.3 特性与游戏运行时兼容，也不代替逐段动作的美术验收。

## 2026-11-08 动画帧与曲线编辑

交互依据 Spine 官方 [Graph](https://esotericsoftware.com/spine-graph) 和 [Dopesheet](https://esotericsoftware.com/spine-dopesheet) 文档。底部提供摄影表与曲线两个视图，采用顶部帧标尺、左侧动画/骨骼/通道列表和右侧数值刻度；旋转通道使用绿色。

- 摄影表以直线、弯线、虚线区分线性、Bezier、阶梯插值，离散轨道和恒值段不绘制数值插值连接。曲线视图按实际控制点绘制连续曲线及方形关键帧。
- 选中关键帧后可切换线性、阶梯、Bezier，或应用圆滑、平坦、缓入、缓出切线。Bezier 段显示两端可拖动控制点；横向控制点限制在相邻帧区间，允许数值超调。
- Shift/Command 点击或框选多帧；摄影表和曲线视图共享关键帧选中状态。批量预设、手柄拖动和关键帧拖动均以一次文档事务提交，可一次撤销。拖动关键帧同时调整时间和值，默认按 FPS 对齐，Shift 拖动取消帧吸附，禁止拖到负时间。
- 曲线图右键/中键拖动平移；滚轮围绕鼠标位置同时缩放时间与数值；Alt+右键拖动分别控制两轴缩放。摄影表右键拖动平移，曲线区滚轮缩放时间，左侧轨道列表滚轮滚动行，Shift+滚轮横移。
- 顶部标尺可拖动定位，当前帧数可直接输入；“适应曲线”聚焦选中帧或全曲线，“自动”随数据调整范围。通道列表支持筛选和隐藏。

## 2026-11-08：已有网格重布、参数描绘和选择恢复

入口仍在图片／网格附件属性顶部的“智能布网”。现在打开隔离贴图的描绘预览，底部包含路径条、标题和关闭、参数表格、描绘／调整、取消／确定。网格外轮廓使用青色线与圆点，图片范围使用白色角标。六个参数均可拖动滑杆或输入数值；参数小数保留，不再被取整：

| 参数 | 当前实现 |
|---|---|
| 细节 | 控制目标轮廓点数；几何和覆盖约束可能使最终点数高于目标 |
| 凹度 | 限制简化后增加的透明区域面积，值越大越保留凹陷 |
| 精度 | 控制轮廓减点搜索和优化次数 |
| 统一 | 对过长的轮廓边均匀补点，不向图片内部填满网格 |
| Alpha 阈值 | 选择需要覆盖的像素 |
| 填充 | 按源贴图像素向外留边 |

算法使用 OpenCV 的 Alpha 连通区域／轮廓，GEOS 的保覆盖外轮廓简化，再通过相邻支撑线求交进行外包减点，最后做约束 Delaunay 三角化。删除任何轮廓点前检查新轮廓有效、覆盖原轮廓、增加面积符合凹度设置。输出还做像素中心覆盖检查。UI 复现参考图的布局和交互，参数数值不代表与 Spine 私有算法一一相同。

修复尾巴失败：`05_tail.png` 除主区域外含 3 像素和 7 像素小岛。现在先应用填充，再以最短窄桥连接剩余小岛，不再直接失败，也不会退回覆盖大片透明区域的全局凸包。1–2 像素孤立噪点被过滤并在预览中计数。孔洞在外轮廓内仍为透明纹理；当前输出是 Spine 单一闭合外轮廓。超过 128 个有效区域或 4096 个轮廓顶点会明确停止。

已有网格：按 UV 三角形重心坐标迁移原绑定位置、权重和所有可编辑 FFD，并同步原始数据中的链接蒙皮／跨蒙皮 FFD。处理导出时的 hull 顶点重排；不修改骨骼和普通动画关键帧。新轮廓超出旧 UV 区域时，几何外推并从最近边迁移权重／变形，报告边界近似顶点数。重新布网不保证动画逐像素完全一致，但可以一次撤销恢复整个旧文档。数值归一化修复了刚性权重出现 `1.0000000000000002` 导致的校验失败。

预览只操作候选数据，确定后才形成一个项目撤销事务。支持鼠标悬停顶点、单选／Shift 多选、框选、拖动；Cmd/Ctrl+Z 和 Shift+Cmd/Ctrl+Z 在预览内撤销／重做顶点调整，取消不改文档。右键／中键拖动预览、滚轮缩放。异步生成带版本标识，关闭后的结果失效；同一视口只允许一个预览，避免旧层拦截点击。普通编辑画布恢复图层悬停轮廓，以及在网格工具下点选其他图层；确定描绘后回到移动工具。

手动拖点重新三角化并迁移权重／FFD，但允许用户主动改变贴图覆盖范围，因此显示“手动调整”，不把自动描绘的覆盖检查当成手工结果的验证。退化或自交轮廓不能确认，保留上一次有效结果供撤销／重试。

## 2026-11-08：自动描绘性能与低细节点数

完整多边形校验从“枚举每个候选都做”改为“用局部鞋带公式计算面积增量并排序，仅检查最优的可行候选”。保留自交、面积上限、覆盖原始轮廓和最终像素覆盖校验；不通过降低贴图分辨率提速。回归测试用几何构造调用次数约束算法工作量，避免依赖易波动的计时断言。
