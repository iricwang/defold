本轮针对网格自身变形补齐编辑器操作，未修改运行时引擎。行为依据 [Spine Mesh attachments / Transform tools](https://esotericsoftware.com/spine-meshes#Transform-tools) 和 [Freeze](https://esotericsoftware.com/spine-meshes#Freeze)。

| 操作 | 修复后行为 |
|---|---|
| 普通工具拖顶点 | 移动、旋转、缩放、倾斜工具都可以直接拖动顶点；选中多个点时一同平移。 |
| 整网格 / 顶点组变换 | 拖动操纵器或非顶点区域可以移动、旋转、缩放、倾斜网格；不再修改所属骨骼。X/Y 手柄限制对应轴，旋转时 Shift 按 15° 对齐。 |
| 多选 | Cmd/Ctrl 点击或框选；中键框选；Cmd/Ctrl+A 选择当前网格全部顶点，不再误选全部骨骼。 |
| 枢轴 | 旋转 / 缩放中心可拖动，靠近顶点自动吸附；与顶点重叠时 Alt 拖动枢轴。枢轴不写入动画数据。 |
| 默认中心 | 整网格使用轮廓顶点中心，局部选择使用选中点中心，内部新增点不偏移整网格中心。 |
| 数值栏 | x/y 编辑当前坐标空间内的顶点中心；旋转、倾斜输入增量角度，缩放输入倍率。输入写入网格变形，避免误改父骨骼。 |
| 关键帧 | 动画模式写 deform 顶点位移；自动关键帧关闭时保留待提交姿态，手动按钮可提交。一次手势一次撤销。设置模式修改绑定位置，保留 UV、权重值及拓扑。 |
| 加权变形 | 世界位移按每个影响骨骼的逆线性变换转换为局部偏移，并考虑权重总和；保留零权重项的布局。 |
