# 四项 Spine 编辑交互修复的二次审查

审查范围：2026-11-13 的响应式底部面板、骨骼/插槽/附件树、连续旋转和数值拖动。发现的问题已直接修复，并扩大回归；不以“上一轮测试通过”替代边界检查。本轮没有修改运行时引擎、安装应用或改动用户工程。

## 发现与处理

| 优先级 | 问题及触发方式 | 修复 |
| --- | --- | --- |
| P1 | 保存骨骼选择组 → 选中图片附件 → 恢复骨骼组 → Delete，旧附件身份或插槽集合残留，导致删除旧图片。复现测试确认了错误目标。 | 选择组/历史恢复包含附件和树选择身份，缺失集合显式清空；画布直接切换对象也清理旧身份。 |
| P2 | 隐藏附件与插槽同名时被误判为活动附件，选择修复反复得到错误类型。 | 活动判定必须有实际附件，选择更新一次完成。 |
| P2 | 附件子行的多选没有进入变换/删除集合；混选可能把子附件与父插槽混淆。 | 保存精确树行身份，活动附件进入变换集合；删除区分显式选中的插槽和子附件，混选统一提交与撤销。播放导致附件活动状态变化时保留其余选择。 |
| P2 | 链接网格及其来源一起删除时，逐项验证可能在中途拒绝；单项删除失败又会清除选择。 | 附件批量删除先构造最终文档，再校验链接；失败保留文档和选择。 |
| P2 | 关闭旋转继承仍把子骨骼当作继承父级，跨圈丢失；镜像父空间忽略旋转方向，最终矩阵等价但转向/圈数错误。 | 检查实际旋转继承链和父空间方向；覆盖五种继承模式、720°、−450°、镜像组 810°。 |
| P2 | 不继承旋转的骨骼，编辑变换反解没有使用与正向计算相同的基底。 | 仅修正编辑器的 authoring compensation；覆盖非均匀缩放、镜像和倾斜下的正反变换。运行时求值私有函数未改。 |
| P2 | 世界缩放框按下时切换到本地值，但拖动记录在事件过滤器里提前读取旧世界值，产生数值跳变。 | 从首次有效拖动时的实际显示值开始累计；保留 Shift、取消、一次提交和撤销行为。 |

另外修正了动画等非对象树行被当成空对象集合覆盖原有选择的问题。
