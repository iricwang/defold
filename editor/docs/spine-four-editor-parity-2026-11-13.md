# Spine 编辑器四处交互差异修复

本轮仅修改编辑器，运行时引擎未改。验证 JAR 用于隔离的后台实例，未安装或热加载到用户当前的 Defold，也未改动用户游戏工程。

## 已实现

| 项目 | 行为 | 验证 |
| --- | --- | --- |
| 窄窗口底部工具栏 | 窄画布或低高度时，底部工具区独占布局空间；横向滚动访问全部工具。宽高足够时恢复悬浮显示，使用同一组控件。 | 400×500、1200×600、1200×300 布局切换；完整编辑器内横向滚动后点击 World 按钮。 |
| 层级树 | 骨骼 → 插槽 → 附件；插槽使用圆环图标，图片、网格、链接网格、路径等分别使用对应图形。列出当前皮肤与默认皮肤的附件；选择备用附件不会切换当前显示。 | 真实点击 05_tail 插槽及网格附件；备用附件选择不改文档；附件删除、重命名保留插槽与父骨骼，支持撤销。 |
| 连续旋转 | 每个鼠标样本累计角度，即使拖动按帧合并，也不丢跨圈信息。动画局部/父级空间保留圈数；设置模式和世界空间使用方向角；Shift 保留角度吸附。 | 810°、−450°，正反方向、合并事件、撤销重做；多选独立骨骼保留圈数，子骨骼不重复旋转。 |
| 数值拖动 | 数值框上下拖动编辑，Shift 十分之一精度，Esc 取消。底部变换数值实时预览、松手一次提交并回到画布焦点。其余数值框松手提交。 | 设置/动画模式、Shift、取消、撤销；自动关键帧关闭时仅产生待提交姿态，取消后保留原有姿态。 |

本轮后台验证另发现并修复了控件重新挂载期间 Scene 暂为空导致刷新计时器停用的问题。树行定位也区分了绘制顺序中的插槽副本。

## 验证结果

- 最终 AOT 编译版：106 tests / 1091 assertions，0 failures / 0 errors。
- 完整编辑器后台实例：51 步真实 JavaFX 交互全部通过。使用 cljfx.plorer，Metal 渲染，包含点击、数值拖动、画布旋转、右键平移、工具切换、播放暂停与撤销。
- 停用的 handlers：0；停止的 timers：0。
- clj-kondo：0 errors；本次修改行新增警告：0（文件中保留 28 条既有警告）。git diff --check 通过。
- 测试项目由 harness 复制到临时目录，未打开用户工程。没有执行原生系统对话框或桌面逐像素一致性验收；本轮没有重跑 Spine 官方运行时逐帧对照，不借用先前结果冒充本轮验证。
- 示例工程的自动 Play 准备仍有既有失败提示；本轮验证对象是骨骼编辑器交互，不将其视为游戏构建通过。

回归场景：`editor/test/headless/skeletal_animation_four_parity.edn`。
证据目录：`editor/docs/skeletal-animation-evidence/2026-11-13/four-editor-parity/`，含后台报告、编译测试日志、源码哈希、lint 与截图。后台报告内的临时截图路径保留原始记录；精选截图已归档。
