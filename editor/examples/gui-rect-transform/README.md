# 原生矩形适配回归项目

使用本分支的新引擎及 Bob，打开 game.project 后运行。项目没有外部依赖。
16 个格子覆盖固定锚点、横向拉伸、纵向拉伸和双向拉伸；运行脚本检查父节点
尺寸变化、实际位置/尺寸读写、屏幕定位、重置和动画完成后的布局。
控制台出现 `RECT_TRANSFORM_RUNTIME_OK` 表示全部运行时断言通过。
传入 `--config=test.enabled=1` 会在动画完成并检查通过后自动退出。

编辑器操作：
- 锚点按钮打开 4×4 预设；普通点击保留当前矩形。
- Shift 同时设置 Defold 九宫格轴心，Alt 同时设置位置；拉伸轴在 Alt 下填满父矩形。
- 固定轴显示位置/宽高；拉伸轴显示左/右或下/上边距。
- Min/Max 可编辑任意有限的归一化锚点范围，Min 不能超过 Max。
- 取消“随父节点适配”会保留当前矩形并返回旧的 Defold 适配方式。

数据：`rect_transform` 是默认关闭的原生开关。`rect_anchor_min/max` 定义父矩形内的锚点范围；
`rect_reference` 保存创作时父矩形的宽、高与轴心；原有 position/size 保存该参考矩形下的值。
父尺寸变化按锚点范围增加尺寸、调整位置，不改变节点 scale。根节点按设计分辨率和安全区域
换算逻辑画布；子节点在父节点的局部矩形中适配。手动尺寸保证切片边框和字体不会被拉伸缩放。

旧引擎不识别这些新增协议字段。使用原生扩展的项目也需要重新编译配套自定义引擎。
