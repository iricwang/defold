# AI Canvas 本地资料管理

更新：2026-11-05

## 当前边界

文档的唯一工作位置是游戏工程内的 `ai-workspace/`。编辑器直接处理文件；Companion 只负责项目聊天归组、职员模型请求、执行队列连接和对话状态。对话里的文件引用是定位信息，不再通过 Companion 下载文件正文。

| 内容 | 本地位置 | 修改规则 |
| --- | --- | --- |
| 创作资料、Markdown、Canvas | `ai-workspace/library/` | 本地编辑；Canvas 检查外部修改，避免覆盖 |
| 职能配表与人员配置 | `ai-workspace/config/` | 随工程迁移 |
| 输入附件 | `ai-workspace/attachments/` | 添加时导入本地，执行前检查文件与哈希 |
| 候选与成果版本 | `ai-workspace/artifacts/`、`candidates/` | 保留内容版本，原始文件改变后产生新副本 |
| Task、审批和验收记录 | `ai-workspace/project/` | 保留人员、任务、版本关联 |
| 交付索引与证据 | `ai-workspace/deliveries/` | 关联正式工程资源和校验值 |
| 游戏运行资源 | `assets/`、`gui/` 等正式目录 | 必须经过资源入库与工程验收 |

## 已简化的流程

1. 文件创建、导入、预览、编辑和索引刷新直接访问本地，不需要连接服务。
2. 执行任务时，将已导入附件的本地路径和哈希写入任务输入；职员直接读取，图片通过图片查看工具打开。没有附件上传，也不产生 `codex-attachments` 重复副本。
3. 职员产出文件后，编辑器读取明确引用的本地源文件，保存内容版本；候选预览直接读取本地版本，不再下载或转码生成第二份预览缓存。
4. 原文件丢失时仅复用校验通过的已有本地版本；文件和本地副本均缺失时提示恢复，不自动生成、下载或覆盖。
5. 本地库索引更新后刷新常驻项目清单。移除“同步资料”按钮、上传失败提示链路以及连接时扫描所有旧聊天的归档任务。

## 必须保留的管理环节

- **人员与任务关系**：AI-PM 提案、人工确认分配、职员执行，不能因为存储本地化而绕过。
- **冲突检查**：Canvas/Markdown 保存前检查外部修改；草稿与已确认成果分别处理。
- **成果版本与审批**：源文件改变应形成新版本。新版本不能继承旧批准状态。依赖任务只准入已确认的固定版本。
- **工程入库与回流**：继续使用入库计划、人工批准、受控写入、编译、运行证据、最终人工验收；普通“保存文档”不等于入库。
- **文件完整性与备份**：提交/复制项目时包含整个 `ai-workspace` 与正式工程资源。旧 Companion 备份不再自动更新，不能当作当前恢复来源。

## 旧项目兼容

首次本地保存/刷新将 `project.json.storage` 更新为 `project-local`，保留项目身份和已有 Codex 项目绑定。旧 `sync.json` 原样保留但停用，并从左侧清单隐藏。已有服务器文件不删除，不做自动下载合并；本地已存在的审批、版本及交付证据不重建。旧项目只在服务端存在的资料，需要另行做一次明确的迁移清单，确认目标及冲突后导出到本地。

已有未确认请求保留原 request ID 和请求体，避免重试造成重复工作；新任务不上传文件。若旧待发请求仍引用已丢失的旧上传回执，应在任务队列中结束该请求并重新分配，不能静默改写原请求的幂等语义。

## 后续值得补齐的功能

按优先级推进，避免重新引入远端资料系统：

1. **受控编辑成果版本**：详情中编辑已冻结 Markdown/图片时，应自动创建工作副本，保存为新 Result 版本，旧审批保持不变。现有哈希准入能发现变更，但编辑入口还需统一为显式新版本，不能依赖发现损坏来保护历史。
2. **重命名/移动与引用检查**：本地管理器先列出 Canvas、Markdown、Task 和交付记录中的引用，再更新可编辑引用；冻结记录保留原版本路径。跨项目迁移优先保持相对路径。
3. **回收站和依赖检查**：删除先显示被哪些任务/成果引用，移到项目回收站并支持恢复；不自动清理正在使用或已批准的文件。
4. **文件变更发现**：对外部编辑、移动、删除进行增量刷新，保留当前 tab、选中项和未保存草稿，避免全目录重载。
5. **项目备份/恢复校验**：导出清单、文件校验、缺失版本报告；优先复用项目 Git/LFS 或文件备份，暂不再做专用同步服务。

暂不增加：全量自动上传、双向同步冲突合并、远端版本号、连接时全量历史扫描、后台自动删除旧版本。
