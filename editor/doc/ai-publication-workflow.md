# AI Canvas 资源发布检查与候选工程

2026-11-06，第 3 批，当前范围为 GUI PNG、静态 Atlas、完整 GUI 与受控引用更新。沿用引擎原生组件、现有 Canvas 与详情布局；任务仍由 Person 执行。

## 使用流程

1. 负责人产出入库方案 Result。Action 详情的“查看入库检查报告”可在人工确认前进行静态检查，查看源/目标摘要、文件大小变化、文本差异及引用更新。这一步不调用编译器、不写正式资源。
2. 人工确认具体方案后，负责人队列执行发布。检查源文件、规则、路径、尺寸、重名、静态图集和工程引用。
3. 将项目普通文件、`game.project`、`.defoldignore`、本地库缓存复制到独立候选工程，应用待发布内容，在独立图和构建目录运行 Defold 资源编译器。复制不使用硬链接；候选失败时正式资源未被写入。
4. 再次检查源文件、目标和整个候选基线。通过后使用已有事务备份、正式写入、最终摘要校验。正式写入阶段出现异常时回退自身写入；遇到外部修改则保留人工文件并报告恢复冲突。
5. Assets 详情可打开本次发布报告。交付收据记录检查器版本、计划、检查批次、候选/最终基线摘要、编译结果及配置/库依赖。报告文件随工程成果冻结，后续检查不覆盖旧交付报告。
6. 运行验证、视觉检查及管理人员验收仍是独立步骤。候选编译通过不能自动验收 Task，也不增加人工验收进度。

## 保护与边界

- 项目入库锁覆盖候选复制、编译到提交，两个入库事务不能同时写入。此锁不阻止外部编辑器直接保存文件，因此写入前后都核对摘要；这是带恢复的多文件事务，不是跨文件系统原子切换。
- 工程普通文件采用保守的整体基线。编译期间任何被纳入基线的文件变化都停止本次发布，需重新生成方案。未保存的相关编辑器资源也阻止编译。
- `build`、`ai-workspace`、`codex-attachments`、Git 元数据和其他隐藏缓存不复制；`.internal` 仅复制库缓存。禁止跟随符号链接与目录联接。
- 检查报告位于 `ai-workspace/deliveries/reports/<plan>/<attempt>.md` 和对应 JSON；最新索引只用于导航。修改方案后旧报告不能作为新方案的差异报告。静态报告是当时的预览，正式执行仍重新检查全部条件。
- 候选与构建输出位于 `.internal/ai-resource-import/<plan>/candidates/<attempt>/`。当前保留以便排查，没有自动清理或全工程回收站功能；大项目复制会占用额外磁盘空间。
- 工程验收时继续核对发布文件、编译依赖，以及 `game.project`、`.defoldignore`、库缓存。收据中的最终基线用于追溯，不意味着持续监控工程的全部文件。
- 保留已有完整 GUI 与控制器，不用拆图预览覆盖页面。静态 Atlas 不支持动画或重命名规则，遇到这些情况仍明确阻止；Sprite/动画、数值、场景/关卡发布按后续类型批次推进。

## 验证

领域回归覆盖：确认前只读差异、缺图、候选失败、人工修改、候选被篡改、相同目标竞争、重试幂等、配置变化、报告保留和事务恢复。原生编译回归使用隔离的 51 节点 GUI、控制器、Atlas、贴图、材质及引用资源；另以错误图集帧验证编译失败不会发布。

最终专项回归为 30 项测试、196 条通过断言，0 失败、0 错误，见开发记录 `tmp/publication-final-tests.log`。覆盖正式写入中途故障的回退与人工文件保留，缺图和错误图集帧在发布前被阻止。新增发布代码 lint 无警告；`ai_canvas.clj` 的既有 `core/some` 警告保留。

同期全 AI 回归为 184 项、1430 条断言，0 断言失败、4 个错误，见 `tmp/publication-all-tests.log`：1 个来自 Windows 创建符号链接权限不足；另外 3 个来自工作区同期修改的总览 UI，旧焦点/分区滚动测试未找到原控件。这套全量回归没有全部通过，不能作为完整工作台验收。最后的专项复测覆盖本批最终代码。
