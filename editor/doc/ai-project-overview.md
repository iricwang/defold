# AI Canvas 项目总览

AI 工程侧栏的“项目总览”打开固定页签。它保留在“关闭其他”和“关闭全部”之后；打开文档或画布不重建侧栏。

## 数据与口径

- 直接读取项目本地的工作登记、职员配表和 `.aicanvas`，不调用 Companion 文档接口。
- 总进度是当前有效 Task 的人工验收比例。验收必须匹配当前任务规格和执行记录，AI 执行结束不等于验收。
- 阶段按来源规划及阶段名称分组；同名的不同规划不合并。
- 执行步骤按 Action 去重，只计最新尝试，不把 Result 确认任务重复计入。
- 未登记到阶段的工作仍纳入执行及异常汇总，失败尝试被成功重试替代后不再报警。
- 待处理包含有效任务分配、方案选择、成果版本审批及工程验收。空白 Task 模板不计数；已验收任务剩余的候选方案保留在原画布，不再催审。
- 成果区区分“已验收”“已入库”“已批准”“待审核”，支持状态筛选；入库计划和验证证据不作为独立交付成果重复展示。
- GUI 优先展示归档的真实视觉验证截图；无截图时显示原生 GUI 入口，不用拆图素材冒充界面效果。

## 操作

顶部支持阶段、工作状态及文本筛选。各分区保留全部匹配内容，通过分区内部滚动查看。任务跳转到对应画布和卡片，成果打开现有详情窗口；审批和执行仍由原卡片流程完成。

采用原生专用组件还原设计稿：连续汇总栏、紧凑阶段行、分段进度、两列执行卡片、三列成果预览，以及固定比例的右侧审核/职员区域。外层面板不滚动，各分区按窗口可用高度分配空间，标题及操作固定，内容独立滚动。项目任务明细始终展示为列表，拥有独立滚动区域。自动刷新保留各分区滚动位置，返回总览时统一复位。底色沿用引擎主题，状态色和组件间距在工作台样式内扩展。

总览保留现有分栏、尺寸、内容顺序、圆形职员徽章和矢量图标，背景、文字、边框及状态色使用引擎主题变量，按钮和输入框继承原生控件样式。移除总览独立的渐变、阴影和纸张底色。成果预览保持原图比例，竖屏界面完整展示，空白处使用引擎预览底色。职能颜色仍来自项目职能配表。样式限定在总览根节点内，避免改变普通 Canvas 卡片和文档阅读器。

阶段行显示负责人职能、前置任务以及执行/待验收状态，并可返回来源 AI-PM。执行卡分别提供任务与对话入口，显示当前 Action、运行时长及记录更新时间；没有时间记录时明确显示缺失。审核项展示责任人和固定版本，并区分分配审阅、方案选择、版本审批和工程验收入口。成果按文档、GUI、素材包区分，显示责任人、不可变版本前缀及文件数量；GUI 节点数从归档 GUI 读取，素材包预览展示实际组件拼排。总览不显示底部最近动态或本地记录状态行。

侧栏保留全部创作分类和本地存储状态。树行采用固定高度，内容能完整容纳时复位原生 VirtualFlow，避免主题刷新后顶部分类移出可见区域；不重建目录树。

“项目总览”与目录树统一使用引擎选中底色和圆角，并互斥显示选中标记。一级目录与总览使用等宽图标占位，文字起点对齐。展开箭头固定在目录行右侧，长名称在侧栏宽度内省略，悬停仍显示完整路径。

从汇总数字或“查看全部”进入筛选视图后，顶部显示“返回总览”。该入口和侧栏“项目总览”均清除状态、阶段、搜索及成果筛选，恢复完整布局，保留已打开的文档与目录树。下拉框收起时使用普通控件底色，蓝色选中态只用于展开后的选项列表。

筛选导航位于标题下方，使用左箭头返回按钮和当前筛选说明，避免标题横向跳动。面板采用 8 像素圆角，内容卡片采用 6 像素圆角，按钮及输入框采用 4 像素圆角，颜色继续继承引擎主题。内容重建前，若焦点位于即将移除的卡片内，先转移到稳定的总览容器，避免菜单刷新读取到脱离场景的焦点；搜索框等持续存在的控件保留焦点。

页面可见时每三秒异步检查本地文件，按文件修改时间和大小缓存。手动刷新强制重读。关闭工作台会停止定时器、取消读取并释放文件句柄。单个文档损坏显示提示；工作登记读取失败时保留上一份统计，避免显示虚假的零进度。扫描超过一万项或单文件超过 32 MB 时提示读取限制。

运行状态来自本地工作记录。执行服务未连接时明确提示状态待核对，不推算虚假的实时百分比。职员列表支持项目的自定义职能配表。

## 验证边界

聚合测试覆盖验收规格/执行版本失效、重试去重、Result 确认排除、跨规划阶段及未纳入阶段的工作。工作台回归覆盖固定页签和关闭生命周期。原生 UI 通过 `cljfx.plorer` 检查筛选、卡片跳转和成果窗口。

开发期间通过统一 Windows 脚本热加载；热加载只影响当前编辑器会话，重启需正式打包后的版本。
