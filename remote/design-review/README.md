## 主导航

沿用 Companion 的固定标题、内容独立滚动和四等分底部图标文字导航。
底色、分隔线和组件密度参考 Companion；强调色保留 Remote 的蓝色。

| 底部 Tab | 用户目标 | 主要操作 |
| --- | --- | --- |
| 游戏 | 找到并开始项目 | 电脑筛选、搜索、开始、继续、查看准备状态 |
| 运行中 | 管理多游戏后台会话 | 切换画面、查看控制设备、查看进度、明确停止 |
| 电脑 | 管理配对及连接 | 添加电脑、查看共享游戏、检查连接、更新地址 |
| 设置 | 调整个人偏好 | 画质、帧率显示、屏幕常亮、帮助与诊断 |

扫码和发现属于添加方式，不作为一级页面。原编辑器直连保留在电脑页的兼容入口，
明确标识其与 Manager 共享项目的区别。一个电脑列表、一个项目列表，取消重复层级。

## 完整路径

首次：`电脑 + → 扫码 / 相册 / 完整链接 → 配对电脑 → 读取项目 → 游戏列表`。

之后：`游戏 → 开始 / 继续 → 自动同步资源 / 本机构建 / 启动 → 游戏画面`。

资源未变化复用已有构建，Lua/GUI 改动优先复用原生引擎。用户不启动构建服务器、
不导入产物、不执行命令。首次编译耗时通过阶段、实际耗时和日志说明，不显示不可靠总百分比。
可以返回列表，后台准备继续；停留在准备页时完成后自动进入画面，否则只更新对应项目状态。

## 返回、停止和切换

- 一级 Tab 切换保留各页的筛选、搜索、滚动位置，不影响电脑上的游戏。
- 普通子页返回上一级；扫码返回电脑页，项目准备/错误返回游戏列表。
- 全屏游戏隐藏主导航，保留靠安全边缘的 48dp 控制入口。四指手势可以兼容，但不作为唯一入口。
- 返回游戏列表：停止本机视频接收并释放触控/控制权，电脑游戏继续运行。
- 停止游戏：单独的明确操作，说明仅停止所选项目，其他游戏保留。
- 点击另一游戏切换串流，旧游戏继续后台运行；已有他人控制时先询问接管。
- App 切后台释放按下状态、暂停视频接收。恢复后重连同一电脑与项目，避免重复创建会话。
- 后台刷新只更新对应状态/行，不重建整页、重启相机或清空用户正在输入的内容。

## 扫码识别专项

### 手机端

1. 相机占满主要区域，仅保留一句取景指引；预览等比显示，取景框与真正分析区域一致。
2. 连续对焦、点按对焦、补光、手势缩放及 1×/2×。长时间未检出时就近提示调整距离，保持相册和链接入口可见。
3. 相册识别走同一二维码解析、身份校验和配对链路。完整链接仅在用户主动粘贴时读取。
4. 检出有效码立即给出取景框高亮和轻震，再进入独立的配对进度；不让用户继续猜测是否已识别。
5. 识别后暂停重复扫描，防止同一帧多次触发配对；失败后可明确恢复扫描。

现有旧 Camera API、预览分析策略和密集二维码都需要实测审查。此次源码检查只能确认
这些实现现状，不能证明某一项就是所有实体手机的识别根因。实现阶段应同时检查镜头选择、
焦距/曝光、分析分辨率、旋转与坐标裁剪、解码耗时和分析背压，不能继续只放大二维码。

### 电脑端与协议

- 二维码大尺寸、高对比、完整留白，整数模块缩放，避免截图或显示缩放造成模糊。
- 缩短编码内容，保留等价强度的一次性凭据和完整电脑身份绑定；兼容旧版二维码解析。
- 使用推荐局域网地址；多网卡放在明确的地址选择中，切换地址使旧二维码失效。
- 展示有效期、自动/手动刷新及“等待识别 / 正在配对 / 已配对”。手机检出后应避免电脑继续轮换当前凭据。
- 保留复制完整配对链接作为替代方式。
- 当前编辑器的 8 位码不能直接用于 Manager。新增短码配对需要额外的协议与安全设计，不在方案中伪装为已有能力。

### 验收目标（待真机验证）

- 至少 3 台不同档位 Android 真机，对真实 Windows/macOS 显示屏扫码。
- 覆盖常用距离、明暗环境、横竖屏和 100% / 150% / 200% 桌面缩放。
- 常用组合每组至少 20 次，目标为 2 秒内识别成功率 ≥95%；困难环境另记录耗时与失败原因。
- 独立记录“相机帧识别耗时/成功率”和“配对网络耗时/成功率”。
- 测试原码、相册截图、旋转、反光、过期码、外部二维码、权限拒绝和相机占用。
- 链接注入、模拟器取景和静态解码测试只能作为分层回归，不能替代真机对屏扫码验收。

## 错误和恢复

| 失败点 | 留在何处 | 处理方式 |
| --- | --- | --- |
| 未识别 | 取景页 | 对焦、补光、缩放、调整距离、相册或完整链接 |
| 非本产品二维码 | 取景页 | 持续提示正确来源，允许继续扫描 |
| 二维码过期 | 取景页 | 电脑刷新后重新扫描，不清除其他配对 |
| 相机权限/占用 | 取景页 | 允许权限/系统设置或相册、链接替代入口 |
| 网络/电脑离线 | 当前电脑配对页 | 保留已识别电脑，检查网络和管理器后重试 |
| 证书/时间 | 当前电脑配对页 | 显示具体原因，检查时间/重新配对，保留校验 |
| 项目编译 | 当前项目页 | 失败阶段、文件/行号、完整日志；修复后点重试，自动重新构建 |
| 本机工具链 | 当前项目页及电脑端 | 同步环境错误，提供电脑端处理入口，不引导云构建 |
| 游戏断线 | 当前游戏画面 | 标注旧帧时间、自动重连、重试、返回列表；不假定离线电脑仍在运行 |

## 实施顺序

1. 先完成导航壳、统一电脑/项目层级、页面状态保留和完整错误上下文。
2. 并行完成相机识别链路与电脑二维码编码/显示改进，用真实相机做识别验收。
3. 接入自动准备、多个后台游戏、可见控制入口及断线恢复。
4. 跑完整交互验收：首次添加、再次连接、无变化启动、编译错误修复、后台返回、接管、停止、横竖屏与辅助功能。

相册、缩放、新导航与紧凑二维码已进入 0.8.0 / 0.2.0。真机识别率仍按上述验收目标单独验证。
